## 四、规格契约（沿用红楼 8 幕紧凑版 V2，不改发布规格）

- **片长 30.4s = 8 幕 × 3.8s**，幕边界 `0/3.8/7.6/11.4/15.2/19.0/22.8/26.6/30.4`；一句一幕硬契约：`eras` 的 `dur` 之和 = `lines.total` = 30.4，`t1` 严格对齐幕边界。
- 8 句旁白，每句 10~16 字、全片 ≥95 字，语速 `+0%`，`zh-CN-XiaoxiaoNeural` + `--sub-style clear`，环境音 ducking。
- 镜头逐幕推近（CAM 表）+ 幕内扫光 + 22 枚大前景粒子，活气中位目标 ≥8%，死帧 <0.10%、跳变 <32%。
- 转场白名单 `organic / crossfade / dotBloom / pageTurn`；**禁** `radiant`（黑色涂鸦）/ `lampGlow`（过曝）/ `ripple`（逐行扭字）。
- 结句深墨底 + 纸白字；封面抽帧**必须先读 `sub.ass` 的 Start/End** 反推无字幕空隙（旁白一改窗口就变，旧 `cover_time` 必须重算）。
- 深色块上的线一律用纸白 / 金色（深墨线画在深赭块上等于没画）；竖向元素不横跨人物头顶（避免「脚手架」）。
- 交付走「分段渲染 → 合成配音 → 活气 QA → 待发箱四件套」，视频号人工上传，自动化只到待发箱。

### 7.6 新增红线 02~05

- **红线 02**：`H.ss(lo, hi, x)` 是 **smoothstep 阈值函数，返回 0..1**，不是 `[lo,hi]` 区间插值。要得到 `[a,b]` 的连续值必须写 `a + (b-a)*ss(0,1,x)` 或 `lerp(a,b,ss(...))`。误用**不抛异常、不报错**，只在静帧上表现为元素整片消失，必须靠像素采样 + 临时 console 探针定位。
- **红线 03**：屏幕空间覆盖层（帘 / 判词卡 / 收印）必须在 camera 的 `c.restore()` **之后**画；在 camera 内再按 BOX 定义一层 clip，两层裁剪求交会吞掉元素。
- **红线 04**：叠加到 rig 上的可选部件（紧箍等）必须同时复现 rig 的 `tilt/lift` 变换与 `alpha`，否则人物淡出后留下悬浮部件。
- **红线 05**：8 幕紧凑版字幕占满 3.3~3.6s/幕，幕间空隙只有 0.2~0.5s 且叠 0.26s 转场，**无法按 `sub.ass` 反推安全无字幕封面帧**（红楼 6 幕片才有 1s+ 空隙）。改用同源「未烧字幕无声片」抽帧：元数据加 `cover_video` 字段，`prepare_channels_remake.py` 优先用它，从根上杜绝「烧录字幕 + 封面标题」双层文字。
